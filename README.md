# 家电延保序列号门户

面向冰箱 / 洗衣机 / 空调用户、品牌经销商与平台审核员的一体化门户：
凭机身序列号查询**购买日期、基础保修期、延保服务状态、可服务维修网点**；
发票缺失时可提交**人工审核**；经销商只能查看**本门店售出**的设备，无法访问全品牌数据。

零第三方依赖，仅需 Node.js ≥ 18。

## 启动

```bash
node server.js          # 默认 http://localhost:3000
PORT=8080 node server.js
npm run smoke           # 端到端冒烟测试（使用临时数据目录，不污染演示数据）
```

首次启动自动在 `data/db.json` 生成演示数据（删除该文件即可重置）。

## 功能与业务规则

### 用户查询（无需登录）
- 序列号自动去空格、转大写后匹配；返回品牌、品类、型号、购买日期、发票状态、售出门店。
- 保修计算（按自然月，UTC 日期避免时区误差）：
  - 冰箱/洗衣机：整机 12 个月，压缩机/电机等核心部件 36 个月；
  - 空调：整机 36 个月，压缩机 60 个月；
  - 延保自**整机基础保到期日**起按月顺延（如基础保 2025-11-02 到期 + 12 个月 → 延保至 2026-11-02）；
  - 状态：`基础保修中` / `延保中` / `已过保` / `购买日期待核实`，到期前 30 天标记"临期"。
- 维修网点：按"品牌授权 + 支持该品类"过滤，同城优先，其次品牌授权点。
- 公开结果**不返回**客户电话等隐私字段。

### 发票缺失 → 人工审核
- 查询页对"无购买日期 / 无发票 / 品牌库无序列号"三种情况均提供审核入口。
- 需填写联系人、电话、城市、≥10 字情况说明；同一序列号+电话存在待审核工单时拒绝重复提交。
- 提交后返回随机工单编号，可在"审核进度查询"凭编号匿名查询（不暴露申请人姓名电话）。
- 审核员**通过**时必须填写核定购买日期（不能晚于今天），系统将其写回设备档案、
  标记 `purchaseVerifiedManually`，保修期限立即按新日期重算；**驳回**必须填写原因。
- 已处理工单不可重复审批。

### 经销商门户（服务端强制隔离）
- scrypt 密码校验 + 不透明 Bearer 会话令牌（12 小时有效期）。
- 设备列表在服务端按 `soldByDealerId === 当前经销商` 过滤；经销商看不到其他品牌、其他门店任何数据。
- 直接猜测他店设备 ID 访问详情时返回 **404**（与"不存在"不可区分，防止存在性探测）。
- 经销商令牌访问管理员接口返回 **403**；未登录访问返回 **401**。
- 支持序列号、品类、保修状态筛选；设备详情含客户信息与关联审核工单。

## 接口一览

| 方法 | 路径 | 鉴权 |
| --- | --- | --- |
| POST | `/api/public/lookup` | 无 |
| POST | `/api/public/reviews` | 无 |
| GET | `/api/public/reviews/:id` | 无（工单编号即凭证） |
| POST | `/api/auth/login/dealer` / `/login/admin` | 无 |
| POST | `/api/auth/logout` | 登录态 |
| GET | `/api/auth/me` | 登录态 |
| GET | `/api/dealer/devices`、`/api/dealer/devices/:id` | 经销商（本店） |
| GET | `/api/admin/reviews?status=` | 管理员 |
| POST | `/api/admin/reviews/:id/approve` `/reject` | 管理员 |

## 目录结构

```
server.js              HTTP 服务 / 路由 / 鉴权 / 审核审批
src/dates.js           UTC 日期与自然月计算
src/auth.js            scrypt 哈希、随机会话令牌
src/warranty.js        保修状态推导、延保计算、网点匹配
src/store.js           JSON 持久化 + 种子数据 + 经销商范围过滤
public/                原生 HTML/CSS/JS 单页应用（三个门户 Tab）
scripts/smoke-test.js  端到端测试（42 项断言）
```

## 安全说明

- 密码使用 `scrypt` + 随机盐存储，登录使用恒定时间比较；
- 所有写接口限制请求体大小，静态资源目录做了路径穿越拦截；
- 前端输出统一 HTML 转义；
- 本项目为演示实现：生产环境应将会话/工单存储替换为数据库、
  为审核进度查询增加申请人手机号校验、并接入真实发票 OCR 与文件上传。
